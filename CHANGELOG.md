# Changelog

Todas as alterações relevantes deste projeto serão documentadas neste arquivo.

O projeto segue o padrão **Semantic Versioning (SemVer)**.

Formato das versões:

- **MAJOR** → mudanças incompatíveis
- **MINOR** → novas funcionalidades
- **PATCH** → correções
